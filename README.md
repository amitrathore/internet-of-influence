# Internet of Influence

Static redesign of the original Carrd page for Internet of Influence / Shoptype Capital.

The site is self-contained for GitHub Pages:

- `index.html` contains the page content.
- `styles.css` contains the full visual system.
- `script.js` contains local reveal behavior.
- `assets/images/` contains downloaded image assets from the original site.

Images, fonts, and scripts are local. The Vimeo video embed is retained from the original Carrd site.
